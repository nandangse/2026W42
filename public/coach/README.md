# Coach photos

Drop Dr Raghu's photographs in here as `1.jpg`, `2.jpg`, … up to `12.jpg`.
JPG or PNG — the app tries `.jpg` first and falls back to `.png`.

One is picked at random each time somebody records a shop-floor update, so the
thank-you is not the same face every time. A missing number is not a problem:
the image simply hides itself and the message stands on its own, which is why
no manifest has to be kept in step with the folder.
